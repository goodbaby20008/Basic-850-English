Basic 850 英语学习教材 · Windows 便携版
==========================================

一、复制到另一台电脑后怎么用

1. 必须复制整个“Basic850-便携版”文件夹。
2. 双击“启动英语学习教材.cmd”。
3. 选择：
   [1] 仅本机使用：自动启动并打开默认浏览器。
   [2] 局域网共享：同一 Wi-Fi 下的手机可用窗口中显示的“手机地址”访问。
   [3] 云服务器：打开可以直接上传的 www 文件夹与本说明。
4. 保持命令窗口打开。按 Ctrl+C 或关闭窗口即可停止服务。

不需要安装 Node.js、Python、Nginx 或其他第三方软件；启动器使用 Windows 10/11 自带的 PowerShell 和 .NET。

二、发布到云服务器

把 www 文件夹内的全部文件上传到网站根目录即可。服务器需要：

- 将不存在的页面路径回退到 /index.html；
- 为 /sw.js 设置 Cache-Control: no-cache；
- 正式域名启用 HTTPS，离线缓存功能才会生效。

云服务器的地址、账号、密钥和控制面板各不相同，因此本启动器不会擅自登录或上传。项目源码中的 deploy/nginx.conf 提供了 Nginx 示例。

三、手机访问说明

局域网共享使用普通 HTTP，学习、音频与本机进度均可正常使用，但浏览器不会安装离线 Service Worker。正式服务器使用 HTTPS 后才支持离线缓存。

进度保存在每个浏览器本机。更换电脑、手机或浏览器前，请在网站“复习”页导出 JSON 备份，再在新设备导入。

四、常见问题

- 浏览器没有自动打开：复制命令窗口中的本机地址手动打开。
- 4173 端口被占用：启动器会自动尝试后续端口，使用窗口实际显示的地址。
- 手机打不开：确认手机与电脑在同一 Wi-Fi，并允许 Windows 防火墙的“专用网络”访问。
- 页面直接双击 index.html 不工作：浏览器会限制本地文件读取，请始终使用启动文件。
