# Word-picture graphics

The SVG files in this directory are unmodified copies of selected graphics from
[Twemoji v17.0.2](https://github.com/jdecked/twemoji/tree/v17.0.2). Twemoji's
graphics are licensed under the
[Creative Commons Attribution 4.0 International licence](https://creativecommons.org/licenses/by/4.0/).

Attribution: Twemoji graphics by the Twemoji project contributors. The Basic
850 project selected the graphics and added its own Chinese alternative text,
learning cues, and exact/approximate teaching labels. Those editorial labels
are not part of Twemoji and do not imply endorsement by the Twemoji project.

`manifest.json` records the upstream URL and Unicode code point used for every
local copy. The source graphics were not visually modified.
