Basic 850 英语学习教材 · Windows 便携版
==========================================

一、复制到另一台电脑后怎么用

1. 必须复制整个“理想城Basic850-便携版”文件夹。
2. 双击“启动英语学习教材.cmd”。
3. 选择：
   [1] 仅本机使用：自动启动并打开默认浏览器。
   [2] 局域网共享：同一 Wi-Fi 下的手机可用窗口中显示的“手机地址”访问。
   [3] 云服务器：打开可以直接上传的 www 文件夹与本说明。
4. 保持命令窗口打开。按 Ctrl+C 或关闭窗口即可停止服务。

不需要安装 Node.js、Python、Nginx 或其他第三方软件；启动器使用 Windows 10/11 自带的 PowerShell 和 .NET。

二、建议配置与最低环境

最低环境：

- Intel/AMD 电脑：Windows 10 或 Windows 11，带 Windows PowerShell 5.1（系统自带）；
- ARM 电脑：Windows 11；
- Chrome 当前稳定版或 Microsoft Edge 当前稳定版；
- 有可用的扬声器或耳机。

推荐环境：Windows 11、Chrome 当前稳定版、可用网络和 Windows Update 服务。第一次安装英语语音时需要网络；正常学习、离线音标 MP3 与本机进度不需要持续联网。

三、声音问题：字母、单词或例句没有声音

音标页面的“单音”是网站自带 MP3；字母、单词和例句使用 Windows 和浏览器提供的英语文本转语音。因此，出现“音标有声、其他英语没声”通常表示电脑尚未安装或没有向 Chrome 提供英语语音。

1. 先在网站右上角点击“声音检测”。
2. 双击本文件夹根目录的“修复英语发音.cmd”。管理员确认框出现时选择“是”。
3. 脚本会安装英语（英国、美国）的基础组件和“文本转语音”组件；它不会修改 Windows 显示语言。完成后彻底关闭并重新打开 Chrome，再点击“声音检测”。
4. 若脚本失败，请确认网络和 Windows Update 服务可用。单位/学校管理的电脑可能禁止下载语言可选功能，请联系管理员。
5. 仍无声音时，检查 Chrome 标签页是否被静音、Windows 音量合成器中的 Chrome 音量，以及耳机或扬声器是否为当前输出设备。

手动备用方法：打开“设置 → 时间和语言 → 语言和区域”，添加“英语（英国）”或“英语（美国）”，在语言选项中安装“文本转语音”。

四、发布到云服务器

把 www 文件夹内的全部文件上传到网站根目录即可。服务器需要：

- 将不存在的页面路径回退到 /index.html；
- 为 /sw.js 设置 Cache-Control: no-cache；
- 正式域名启用 HTTPS，离线缓存功能才会生效。

云服务器的地址、账号、密钥和控制面板各不相同，因此本启动器不会擅自登录或上传。项目源码中的 deploy/nginx.conf 提供了 Nginx 示例。

五、手机访问说明

局域网共享使用普通 HTTP，学习、音频与本机进度均可正常使用，但浏览器不会安装离线 Service Worker。正式服务器使用 HTTPS 后才支持离线缓存。

进度保存在每个浏览器本机。更换电脑、手机或浏览器前，请在网站“复习”页导出 JSON 备份，再在新设备导入。

六、常见问题

- 浏览器没有自动打开：复制命令窗口中的本机地址手动打开。
- 4173 端口被占用：启动器会自动尝试后续端口，使用窗口实际显示的地址。
- 手机打不开：确认手机与电脑在同一 Wi-Fi，并允许 Windows 防火墙的“专用网络”访问。
- 页面直接双击 index.html 不工作：浏览器会限制本地文件读取，请始终使用启动文件。
- 提示“不是内部或外部命令”：这是旧版启动文件的编码问题。请删除旧副本后，重新复制最新版完整“理想城Basic850-便携版”文件夹，不要只替换 www 或单独复制 cmd。
